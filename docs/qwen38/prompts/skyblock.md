# Fase 1a: esqueleto mínimo

Crea `index.html` con una escena Three.js **mínima**:

- `<script src="./vendor/three.min.js"></script>` y el global `THREE`; sin CDN,
  sin ESM, sin descargas.
- Una isla de un solo bloque de hierba de 5×5×1 flotando en el cielo.
- Cielo con color cálido, una luz direccional y una luz ambiental.
- Cámara en una posición cinematográfica mirando al centro.
- Órbita manual con pointer/wheel, con límites; sin addons.
- Overlay con el título **Skyblock Chill** y la ayuda
  «Arrastra para orbitar · Rueda para zoom».
- Todo el CSS/JS inline, responsive, `pixelRatio` máximo 2.
- **Máximo 120 líneas.** Sin agua, lava, árboles, animales, flores ni partículas.

## Cómo trabajar

- **La primera acción debe ser `archivo`** con el HTML completo. No escribas un
  plan ni el código en tu razonamiento; piensa solo lo imprescindible y llama a
  la herramienta.
- Después lee el archivo para comprobar que cierra bien y que no hay recursos
  externos.
- Responde con un resumen breve.
