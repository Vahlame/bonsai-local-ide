# Bonsai 2 Uncensored Shootout

I ran all eleven uncensored Ternary Bonsai 2 27B builds on Hugging Face through the same prompts with the same judge. Each build is scored on answer quality, refusals, thinking mode, MMLU and HumanEval, and each file is compared digit by digit against PrismML's release.

The report is a single static page (`index.html`). Every tested file is pinned by sha256 in its appendix.

Base model: [prism-ml/Ternary-Bonsai-2-27B-gguf](https://huggingface.co/prism-ml/Ternary-Bonsai-2-27B-gguf) (Apache 2.0).
